## 🏦 Bank Management System (Spring Boot + React)

## 📌 Overview

The **Bank Management System** is a Full-Stack web application developed using **Spring Boot (Java Backend)** and **React (Frontend)** with **MySQL Database** integration.

This project allows users to perform essential banking operations through a modern and responsive web interface while ensuring secure backend processing using REST APIs.

It demonstrates real-world full-stack development concepts including:

- RESTful API development  
- Database integration  
- Layered architecture (Controller → Service → Repository)  
- Secure data handling  
- Frontend-backend integration  

---

## 🚀 Features

- ✅ Create New Bank Accounts  
- ✅ Deposit Money  
- ✅ Withdraw Money  
- ✅ Transfer Money Between Accounts  
- ✅ Check Account Balance  
- ✅ View Transaction History  
- ✅ Secure REST APIs using Spring Boot  
- ✅ Responsive UI using React  

---

## 🏗️ System Architecture

### 🔹 Backend (Spring Boot)

- Built using **Spring Boot**
- REST APIs developed using `@RestController`
- Uses **Spring Data JPA**
- Follows layered architecture:
  - Controller Layer  
  - Service Layer  
  - Repository Layer  
- Uses **MySQL Database**
- Global Exception Handling implemented
- Transaction management using `@Transactional`
- Prevents SQL Injection via JPA & Prepared Statements  

---

### 🔹 Frontend (React)

- Built using **React JS**
- Uses Axios for API communication
- Modern and responsive dashboard UI
- Component-based architecture
- Handles real-time user input and server responses
- Separate components for:
  - Create Account  
  - Deposit  
  - Withdraw  
  - Transfer  
  - View Transactions

## 🗄️ Database Details

- **Database:** MySQL  
- Stores:
  - Account Details  
  - Transaction Records  
- Relational schema with primary & foreign keys  
- CRUD operations handled via JPA Repository  

---

## 🔄 How It Works

1. User interacts with the React frontend.
2. React sends HTTP requests using Axios.
3. Spring Boot receives the request through REST Controllers.
4. Service layer processes business logic.
5. Repository layer communicates with MySQL database.
6. Response is returned to frontend and displayed dynamically.

---

## ▶️ How to Run the Project

### Backend (Spring Boot)

1. Open the backend project in IntelliJ / Eclipse.
2. Configure MySQL credentials in `application.properties`.
3. Run the main Spring Boot application.
4. Backend runs on: http://localhost:8080


---

### Frontend (React)

1. Navigate to frontend folder.
2. Install dependencies:
npm install

3. Run the project:
  npm run dev


4. Frontend runs on: http://localhost:5173
